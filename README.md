# TinyML Mid-Sem Interactive Revision Tool

Interactive study guide, formula calculator, and question bank for TinyML.
Includes:
- QAT (Quantization-Aware Training) numericals & steps
- Quantization (Symmetric / Asymmetric scales & zero points)
- CNN Parameter Counting (Conv2D, Dense, Depthwise separable)
- Deployment (TFLite Micro, Tensor Arena, OpResolver)
- Model Compression (Knowledge Distillation, Pruning)
- Morning 30-min Glance Sheet with step-by-step calculations
- Last 10-min Formula Sheet
- Split View mode for side-by-side comparison
